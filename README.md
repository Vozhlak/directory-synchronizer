# Directory Synchronizer

Консольная утилита для синхронизации двух директорий на Go. Сканирует исходную и целевую папки, сравнивает содержимое по SHA256-хешам и выполняет необходимые операции: копирование новых файлов, обновление изменённых и удаление лишних.

## Установка и сборка

### Требования

- Go 1.25 или новее

### Установка зависимостей

```bash
go mod download
```

### Сборка

```bash
go build -o sync main.go
```

Или запуск без сборки:

```bash
go run main.go <source> <dest>
```

## Примеры использования

### Базовая синхронизация

```bash
# Синхронизировать ./source с ./dest
go run main.go ./source ./dest
```

### Синхронизация с вложенными папками

```bash
go run main.go ./project/src ./backup/project/src
```

## Ключевые возможности

- **Рекурсивное сканирование** — обход всех вложенных директорий через `filepath.WalkDir`
- **SHA256-хеширование** — точное сравнение содержимого файлов, а не только имён
- **Конкурентная обработка** — worker pool с 10 горутинами для параллельного вычисления хешей
- **Параллельное сканирование** — одновременное сканирование source и dest директорий
- **Атомарные операции** — копирование, обновление и удаление файлов с обработкой ошибок
- **Создание структуры** — автоматическое создание необходимых поддиректорий через `os.MkdirAll`
- **Прогресс-бар** — визуализация прогресса синхронизации в реальном времени
- **Цветной вывод** — зелёный (копирование), жёлтый (обновление), красный (удаление)
- **Отказоустойчивость** — продолжение работы при ошибках отдельных файлов

## Как это работает

1. **Сканирование** — утилита рекурсивно обходит обе директории и вычисляет SHA256-хеш для каждого файла
2. **Сравнение** — сравниваются карты `путь → хеш` для выявления различий
3. **Синхронизация** — выполняются операции:
    - **Копирование** — файлы, которые есть в source, но нет в dest
    - **Обновление** — файлы с одинаковым путём, но разным хешем
    - **Удаление** — файлы, которые есть в dest, но нет в source
